# IPL Analytics Dashboard

This project analyzes IPL cricket datasets using Python, Pandas, Matplotlib, and Streamlit.

## Features
- Data Cleaning
- Exploratory Data Analysis
- Visualizations
- IPL Dashboard

## Tech Stack
- Python
- Pandas
- Seaborn
- Matplotlib
- Streamlit
- Plotly
- Jupyter Notebook

## Streamlit Dashboard

Features:
- Season Filters
- Team Filters
- Player Filters
- Team Analysis
- Player Analysis
- Interactive Plotly Charts
